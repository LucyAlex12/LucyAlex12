# Setup

This folder is ready to become your GitHub profile README repository.

## What to create on GitHub

1. Create a new public repository named exactly `LucyAlex12`.
2. Add the files from this folder to that repository.
3. Commit to the default branch, usually `main`.
4. Open the repository Actions tab and allow workflows if GitHub asks.
5. Run the `Generate contribution snake` workflow once.

After that, your GitHub profile page at `https://github.com/LucyAlex12` will show the new README.

## Optional improvements

- Add a playable game repository once you have one published.
- Add screenshots or GIF demos for your strongest projects.
- Pin your strongest repositories on GitHub after publishing this profile README.
